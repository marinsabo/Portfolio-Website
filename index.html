Modernisation

From datasets to Git

After DartZ was finished, we changed how it’s built and delivered, following IBM Dependency Based Build. The source of truth moved off the mainframe into Git, and a pipeline now delivers every committed change to z/OS automatically.

  1. VS CodeCOBOL, JCL and copybooks edited locally
  2. GitSingle source of truth, where every change is a commit
  3. PipelineStarts automatically on each push
  4. IBM DBBBuilds the programs affected by the change
  5. Zowe → z/OSChanges land on the mainframe
