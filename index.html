Modernisation DevOps

From datasets to Git

After DartZ was finished, we changed how it’s built and delivered, following IBM Dependency Based Build. The source of truth moved off the mainframe into Git, and a pipeline now delivers every committed change to z/OS automatically.

Before Source lived in mainframe datasets, and builds were run on the host with JCL.
After Source lives in Git. A commit triggers the pipeline, which builds and delivers the change to the mainframe.
  2. 01VS CodeCOBOL, JCL and copybooks edited locally
  3. 02GitSingle source of truth, where every change is a commit
  4. 03PipelineStarts automatically on each push
  5. 04IBM DBBBuilds the programs affected by the change
  6. 05Zowe → z/OSChanges land on the mainframe
